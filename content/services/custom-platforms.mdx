Building a platform is mostly about deciding what not to build yet. We help you ship a first version quickly, learn from real users and grow it from there.

## How we work on platforms

- **Small first release.** The shortest path to something real people can use.
- **Solid foundations.** Typed code, tests and a database design that will not need rewriting in six months.
- **Weekly demos.** You see working software every week, not a big reveal at the end.
